# 退货退款政策

## 七天无理由退货适用范围

自签收之日起 7 个自然日内，商品未影响二次销售的，支持无理由退货。签收当天不计入 7 天，从次日 0 点开始计算。

## 不支持七天无理由的商品

以下商品不适用七天无理由退货：

- 消费者定作的商品
- 鲜活易腐商品
- 在线下载或消费者拆封的音像制品、计算机软件等数字化商品
- 已拆封的贴身衣物、化妆品、食品
- 拆封后影响二次销售的商品

## 退货商品的状态要求

商品需保持原有品质、功能，商品本身、配件、商标标识齐全。商品有使用痕迹、人为损坏、缺少配件的，商家有权拒绝退货或扣除相应折损费。

## 退款到账时效

退货商品经商家验收合格后，退款按原支付渠道退回：

| 支付方式 | 到账时效 |
| --- | --- |
| 支付宝 / 微信支付 | 1 至 3 个工作日 |
| 银行卡 | 3 至 7 个工作日 |
| 花呗分期 | 3 至 5 个工作日 |
| 余额 / 礼品卡 | 24 小时内 |

退款金额不包含已使用的优惠券，优惠券在退款后按原规则退回账户。

## 部分退货

同一订单包含多件商品时，支持部分退货。部分退货后订单实付金额不满足满减门槛的，剩余商品需补回优惠差额。
